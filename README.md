# Diabetes Screening Through Retinal Image Analysis

A deep learning project developed as part of my BSc (Hons) Software Development studies. The system explores the use of retinal images and Convolutional Neural Networks (CNN) to support diabetes screening.

## Project Overview

The project applies image processing and deep learning techniques to retinal images. A CNN-based approach is used to analyse image features and demonstrate how artificial intelligence can support image-based health screening applications.

## Key Features

- Retinal image processing
- Convolutional Neural Network (CNN)
- Deep learning-based image analysis
- Image classification
- AI-assisted screening approach
- Web application integration using Django

## Technologies

- Python
- Django
- CNN
- Deep Learning
- Image Processing
- Retinal Imaging

## Purpose

The project demonstrates the application of software development, artificial intelligence, and deep learning techniques to retinal image analysis for diabetes screening.
